# llama.cpp Benchmark

This directory contains the benchmarking code for the llama.cpp server implementation.

## Prerequisites

- llama.cpp built and installed with the `llama-server` binary available in your PATH
- Python 3.8+ with the `requests` package installed

## Running the Benchmark

### Option 1: Let the benchmark start the server

The benchmark script can automatically start the llama.cpp server with the specified model. By default, it will use `bartowski/DeepSeek-R1-Distill-Qwen-7B-GGUF` as the model.

```bash
# Run from the project root directory
python -m benchmark.benchmark_runner --implementation llamacpp

# Or specify a different model using an environment variable
LLAMACPP_MODEL="/path/to/your/model.gguf" python -m benchmark.benchmark_runner --implementation llamacpp

# Save results to a specific file
python -m benchmark.benchmark_runner --implementation llamacpp --output my_results.json
```

### Option 2: Start the server manually

If you prefer to start the llama.cpp server manually with your own configuration:

1. Start the server:
   ```bash
   llama-server -m /path/to/your/model.gguf --host 0.0.0.0 --port 8080
   ```

2. Run the benchmark (it will detect the running server):
   ```bash
   python -m benchmark.benchmark_runner --implementation llamacpp
   ```

## Configuration

The benchmark can be configured through the following environment variables:

- `LLAMACPP_MODEL`: Path to the model file or Hugging Face model identifier (default: `bartowski/DeepSeek-R1-Distill-Qwen-7B-GGUF`)

## Metrics

The benchmark collects the following metrics:

- **Response text**: The text generated by the model
- **Latency**: Total time taken for the request in milliseconds
- **Tokens per second**: Generation speed in tokens per second
- **Time to first token**: Time to receive the first token in milliseconds

## Testing Independently

You can test the llama.cpp benchmark implementation directly:

```bash
python local/llama_cpp/run_benchmark.py
```

This will run a simple test query and report the metrics.
